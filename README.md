## Практическая работа №3. Свойства и инкапсуляция

### Защита здоровья

Запрет записи снаружи и проверка числа это разные вещи. Health закрыт для записи через private set, поэтому alexander.Health = -100 не компилируется. Само число проверяется в конструкторе и в методах.

В конструкторе проверяется начальное здоровье, в TakeDamage и Heal проверяется изменение.

Name = name в конструкторе запускает set свойства, там значение попадает в value, проходит проверку и Trim, потом сохраняется в _name.

Правило 0 <= Health <= MaxHealth проверил так: герой с -100 получил 0/100, герой с 5000 получил 200/200. После TakeDamage(5000) здоровье 0, после Heal(5000) стало 150.

### Защита количества в book

Правило: количество не может быть отрицательным.

Проверяется в конструкторе и в Restock.

Создал книгу с count -5, получилось 0. После Restock(-2) количество осталось 6.
